你需要绘制一张可直接用于 2D 游戏的“月汐海岸”完整户外探索地图。画面采用统一的大颗粒像素密度、深棕紫色描边、柔和配色与日式 kawaii 气质，让场景适合承载软萌的 chibi 玩家角色。最终输出以环境地图为唯一主体。

## 场景定位

- 呈现一处安静、治愈的日式海岸与临海小站，带有模拟经营游戏和慢生活游戏的日常感。
- 时间是晴朗的夏日白天，阳光柔和温暖，海风轻缓，整体氛围明亮、放松、适合散步。
- 画面是一张能够承载角色移动和探索的大范围完整游戏地图。整张输出覆盖多个游戏镜头范围，游戏运行时通过相机窗口显示其中一部分，角色移动后能够继续看到相邻区域。

## 视角与构图

- 使用 16:9 横向画布，采用与《星露谷物语》户外地图相同空间阅读方式的 fixed orthographic elevated top-down game map view。以这种镜头和地图投影作为视角基准，具体美术设计遵循本提示词中的像素画风格与调色板。
- 镜头固定在场景高处并朝向地面，画面主体是连续地表以及候车棚、列车和植物的顶部。使用正交地图投影，平行线始终平行，铁路在画面各处保持相同宽度，所有物件保持一致的地图尺度。
- 整张画面从上到下均由连续的陆地和海面铺满至画布边缘，地图上方边缘继续延伸沙地、植被、铁路与水面。候车棚显示少量统一的正面和侧面，同时清楚呈现屋顶及其占地关系。
- 保持统一的像素密度和物件尺度，通过增加地图覆盖的空间范围来容纳更多可探索区域。各处地标疏朗分布在多个游戏镜头范围内，铁路、小路、沙滩和植被区域向画布边缘自然延伸，使画面呈现大型连续地图的一部分。
- 海岸线自然纵向延伸，将画面分成左侧陆地与右侧海面。
- 右侧约 30% 是从上方俯视的蓝绿色海面与近岸浅滩，使用层叠的像素浪花、浅色水纹和少量潮池表现平静海水。
- 左侧约 70% 是能够承载角色活动的陆地区域，以大面积浅金色沙滩为主体。最左侧布置沿海延伸的单线非电气化铁路和一座小型临海车站，沙滩中的自然小路连接站台、海岸与上下方向的地图边缘。
- 沙滩、站台与小路共同形成连贯、容易辨认的可行走区域，障碍物边界和出入口清楚，路径与场景物件遵循统一的逻辑像素比例尺。

## 主要地标

- 海面中右侧绘制“幻月岩”：一块与岸边保持距离的孤立深灰褐色礁石，采用紧凑、醒目的轮廓，周围保留开阔水面。
- 幻月岩上生长几株低矮、受海风影响而微微倾斜的古松，树干与枝叶以成簇像素表现。
- 场景中的人工设施集中在最左侧，由单线铁路和一座规模很小、带有生活感的临海车站构成：简洁的单侧站台、小型木质候车棚、长椅、站牌和矮木栅栏。车站以俯视地图物件的统一尺度呈现，屋顶、站台边缘和出入口清楚可读。
- 站台旁停靠一节复古朱红色 KiHa 40 形单节列车。列车外形方正厚重，从上方清楚看到车顶的空调外机和排气管，车头上方有一盏单孔探照灯。列车与铁路保持统一正交投影，以地图中的小型交通地标尺度融入场景。

## 环境细节

- 沙滩使用浅金沙地、湿润深金沙地和浅色潮线形成自然弯曲的层次，加入低缓沙丘边缘、缓坡和局部潮水冲刷纹理，丰富大面积陆地的地形变化。
- 在沙滩和站台周围点缀海滨野草与少量低矮灌木，使用木栅栏、固定的地形石块、沙滩脚印与弯曲小路组织行走空间，让场景具有可探索的游戏地图感。
- 陆地区域保留大块连贯、干净开阔的沙地、小路和自然留白，环境细节疏密有序，为角色移动和后续独立资产布置提供充足空间。
- 场景范围聚焦近海、浅滩、沙滩、铁路与小站，地图边缘延续同类海岸地形。

## 逻辑像素与比例尺

- 将 5504×3072 的 4K 输出画面表现为 688×384 logical pixels 的逻辑画布，每个 logical pixel 对应一个对齐的 8×8 输出像素方块。
- 所有像素方块使用统一尺寸和清晰硬边，轮廓沿逻辑像素网格形成明确的水平、垂直与阶梯状线条。
- 使用 32×32 logical pixels 作为基础地图单位，地形转折、站台边缘、铁路、栅栏和固定物件遵循这一尺度节奏。
- 场景按约 96 logical pixels 高的 chibi 玩家精灵预留比例，主要可行走路径保持至少 64 logical pixels 宽，站台、候车棚、长椅和列车与这一尺度自然协调。
- 主要物件轮廓保持 1～2 logical pixels 粗，内部明暗以连续的像素簇组织，细节密度在整张地图中保持一致。

## 像素画风格

- 呈现精致、治愈的日系 pixel art farming and life simulation game map。
- 使用统一的 logical pixel grid、明确的阶梯状轮廓、成簇明暗和少量 cel shading。
- 轮廓统一使用深棕紫色和柔和深蓝灰色。
- 使用有限且协调的调色板：浅金沙色、奶油黄、海水青蓝、浅滩水蓝、松针柔绿、列车复古朱红色。
- 海浪、沙纹、树叶、木材与岩石都通过规整的大颗粒像素块和清晰的像素簇概括。
- 输出纯净的游戏地图画面，画面内容完整聚焦月汐海岸环境本身。
