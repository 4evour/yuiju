根据提供的两张参考图，创作一张可用于 2D 像素游戏的角色基准图（canonical game sprite）。画面以一个完整角色为主体，不需要生成 sprite sheet 或动画序列帧。

参考图：
- 图一是 Pixel Art Style Reference，主要参考具有明确颗粒感的大块像素、阶梯状轮廓、成簇的明暗关系、有限调色板、朝右的四分之三视角和日式 Q 版游戏角色质感。
- 图二是 Character Design Reference，主要参考角色的外观设定：浅金色双马尾、紫色眼睛、浅蓝色发带、奶油黄开衫、白色内搭、浅蓝色百褶裙、白色堆堆袜和棕色乐福鞋。头戴一顶低矮扁圆、贴合头顶的白色贝雷帽；帽子右前侧装饰一个小巧的白色蝴蝶结，蝴蝶结采用紧凑的双环结造型，结尾收拢在帽边。
- 开衫内是白色水手领，水手领边缘装饰两条细窄的奶油黄色襟线，胸前系着一个浅蓝色领结。

角色设计：
- 将图二中的少女设计成约 2.5 头身的 chibi game sprite，头部偏大，身体和四肢短小，整体轮廓紧凑、圆润且容易辨认。
- 保留 kawaii、温顺、软糯和略带羞涩的少女感，使用圆润亲和的脸型、通透的紫色眼睛、柔和腮红和轻微微笑。
- 服装和发型以像素画方式概括，通过规整的像素块、简练的轮廓和有限色阶表现关键特征，色彩以奶油黄、浅蓝、浅金、柔粉和淡紫为主。

姿势与脚部基线：
- 使用朝右的四分之三全身视角（right-facing three-quarter full-body view），角色保持放松、稳定的中性站立姿势。
- 头部、躯干和双脚自然朝向画面右侧，近侧与远侧的身体结构符合四分之三视角，双臂放松垂在身体两侧。
- 角色处于静止站立状态，近侧腿和远侧腿并列支撑身体，两侧膝盖与脚踝位于相同高度。
- 双脚之间留有少量间距，并处于同一个深度平面，两只鞋完整平放在同一水平地面上。
- 近侧鞋底与远侧鞋底从鞋跟到鞋尖共享同一条不可见的水平 ground baseline，左右鞋底的最低像素具有相同的垂直坐标。
- 四分之三视角通过鞋面可见面积和外轮廓表现，双鞋的落地高度保持一致。
- 将 ground baseline 作为不可见的构图参考线，不在最终画面中绘制线条。
- 站姿适合作为后续待机、眨眼和行走动画的 canonical frame。

画布与构图：
- 使用 1:1 正方形画布，角色位于画面水平中心附近，可见高度约占画布的四分之三到五分之四。
- 双鞋、头顶和双马尾完整可见，角色四周保留适量空间。
- 角色的身体中心与双脚中点自然对应，使整体重心显得平稳。

像素画风格：
- 呈现为精致的日系 kawaii pixel art game sprite，带有规整统一的 logical pixel grid。
- 轮廓使用明确的阶梯状像素和稳定的深棕紫色描边，像素块边界明确。
- 通过成块的阶梯明暗、少量 cel shading 和像素高光表现头发、针织开衫、裙子与鞋子的质感。
- 整体色调明亮温暖、柔和低饱和，高分辨率画布用于保留规整的大颗粒像素细节。

背景与游戏资产表现：
- 背景使用均匀的纯亮绿色 chroma key，颜色为 #00FF00。
- 画面保持简洁，以单个完整角色和纯色背景为主，不加入场景、地面、投影、文字或界面元素。
- 角色自身的配色与绿色背景保持明显区分，方便后续去除背景并制作透明游戏资产。
